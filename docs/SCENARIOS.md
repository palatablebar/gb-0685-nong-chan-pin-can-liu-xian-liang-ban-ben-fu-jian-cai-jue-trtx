# 检测场景

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

## 名称裁决场景（aliases.csv）

- `Ｐ０１`（全角）经 NFKC 规整唯一命中 `P01`，AUTO 直接判级，并作为同样本复检替代初检。
- `红富士`、`apple`（产品旧称/外文简称）与 `有机磷P01`、`甲拌磷项`（项目旧称/科室简称）在院内登记表有归并目标，但默认 PENDING，必须人工 CONFIRMED 后才采信限量；归并后仍由方法适用范围等下游规则把关。
- `P010`、`P10` 与 `P01` 编号相近，只给相似度候选，默认暂缓；复核员可逐条确认、拒绝（ALIAS 隔离）或保持暂缓，两个名称互不影响。
- 关系变化只重算受影响名称对应的项目；同源重跑不新增别名、不改写已确认关系；非法归并目标被拒绝时旧版结果保留。原始报告名称在全链路（m2–m7 及归档 CSV）保形留证。
