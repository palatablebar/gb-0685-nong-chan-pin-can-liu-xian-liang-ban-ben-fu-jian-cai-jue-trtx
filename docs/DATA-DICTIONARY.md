# 检测区间与复检

采样日期选择限量标准[start,end)，不使用报告出具日。同产品同残留项目在采样日须恰有一条有效标准，方法须在适用范围内。浓度统一mg/kg，ug/kg与ppb乘0.001，ppm等于mg/kg。检出限LOD必须大于0。

定量值以[value,value]记录，低于LOD的定量值拒绝。ND或<LOD以[0,LOD)记录，<后的数值必须等于报告LOD。区间上界≤限量为PASS，下界>限量为FAIL，其余UNCERTAIN。<0.01相对0.005限量为不确定，不能当零。

复检relation指向原报告，必须同样本、同批次、同产品、同残留项目、同方法、同采样日，报告日严格更晚。引用环、悬空引用与异样本引用隔离。每样本/项目只允许一个原始报告根。有效复检按reported、version取最新；并列结果矛盾拒绝。其他残留项目不因复检被覆盖。批次按FAIL>UNCERTAIN>PASS取最高风险等级。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同一报告ID的多个版本先选最高version，再构建复检引用链；历史版本留作采信证据，不重复参与最终项目判定。

## 名称裁决（m2 项目映射）

报告中的产品 `product` 与残留项目 `analyte` 可能使用全角字符、简称或院内旧称，名称关系分为四类，只有前两类可作为限量匹配与判级依据：

- `AUTO` 逐字一致（`EXACT`），或 NFKC 全角/半角、兼容字符、空白、大小写规整后与限量标准名唯一一致（`NFKC_FULLWIDTH`、`KEY_NORMALIZE`）。字符层面无歧义，系统自动确认。
- `CONFIRMED` 院内登记简称/旧称（`ALIAS_TABLE`）或相似名称，经复核员人工确认归并到具体标准名。
- `PENDING` 编号/品种相近（`SIMILAR_CODE`、`SIMILAR_NAME`），只给候选与相似度证据，默认暂缓：不隔离、不判级、不套限量。
- `REJECTED` 复核员拒绝归并，相关行以 `ALIAS` 原因码隔离，原始名称在隔离证据中保留。

报告原始名称始终保形存放在 `product_raw`、`analyte_raw`，归并后的标准名写入 `product`、`analyte` 供限量选版使用；暂缓行存放在 `held_rows`，名称裁决清单存放在 `name_decisions`。人工关系持久化于独立 `aliases` 表，运行指纹（run_id）纳入关系快照：同源重跑且关系不变时幂等，不新增别名、不改写已确认关系；关系变化只重算受影响名称对应的项目，其他项目结论保持不变。归并目标不在限量标准名称表、字段或状态非法时拒绝写入并保留旧版运行结果。对账口径：输入=采纳+隔离+暂缓+空行+重复表头+完全重复。
